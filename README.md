# Linux
## Linux Commands for DevOps Engineer
**System Info:**
- hostname  -- show hostname
- whoami    -- current user
- date      -- current date
- uptime    -- system uptime
**Directory Navigation:**
  - pwd     -- Present working directory
  - ls      -- List files
  - ls -l   -- Detailed list
  - ls -a   -- Show hidden files
  - cd      -- Change directory
  - Help command -- man ls (manual)
**File Management:**
  - touch   -- Creates an empty file
  - cat     -- To display the content of the file
  - less    -- Opens hte file for scrollable and searchable viewing
  - head    -- Shows first 10 lines
  - tail    -- Showa the last 10 lines
  - cp      -- To copy the files
  - mv      -- Moves or renames the file
  - rm      -- To delete the file
  - rm -rf folder/ — Forcefully deletes a folder and all its contents recursively.
